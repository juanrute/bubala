    # bubala
    A .NET Core back-office REST API for managing the operations of a fruit pulp distribution company (Real case for a family entrepreneurship).

    This project serves as my public portfolio to demonstrate my expertise in the .NET ecosystem. It includes a RESTful API built with .NET Core and MongoDB, containerized with Docker. Key features include:

    Authentication and authorization

    Caching strategies

    Clean architecture following SOLID principles

    Use of modern tools and patterns (e.g., MediatR, vertical slice architecture)

    This project is also a sandbox for exploring and applying new technologies, and it represents my commitment to writing clean, maintainable, and scalable code. It will serve as a technical introduction to my skills for future opportunities.
